# Real-Time Chat Application

A real-time messaging application that allows users to communicate through instant messaging. Built with a modern web frontend and a Node.js backend, with support for real-time communication and media sharing.

## Technologies

- JavaScript
- Vite
- Tailwind CSS
- DaisyUI
- Node.js
- Socket.IO
- Cloudinary
- MongoDB / MySQL
- AWS Cognito

## Key Features

- User authentication
- Real-time messaging
- Media sharing
- Responsive user interface
- Database integration

## Getting Started

1. Clone the repository.
2. Install dependencies for the frontend and backend.
3. Configure environment variables.
4. Start the backend server and frontend development server.
